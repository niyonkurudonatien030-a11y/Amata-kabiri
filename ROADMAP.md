# Roadmap (summary; full table is in the project book, Part E)
Stage 1 (now): working MVP, demo with fictional data, field validation with real users.
Stage 2: SMS/WhatsApp notifications, Kinyarwanda UI, PostgreSQL, HTTPS deployment, security review.
Stage 3: cooperative and collection-centre integration, analytics, anomaly flags.
Stage 4: USSD, voice, route optimisation, authorised mobile-money integration (needs legal/financial partners).
Every stage needs real user feedback before the next starts.
